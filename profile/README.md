AKCybex is a software development and IT services company. We partner with startups and established businesses to take products from idea to production, build our own SaaS products, and publish the tooling we create along the way as open source.

<br>

## What we do

**Custom software** &nbsp;—&nbsp; Web applications, APIs, admin panels, e-commerce storefronts and internal tools.<br>
**Mobile apps** &nbsp;—&nbsp; Cross-platform apps built with React Native and Expo.<br>
**IT services** &nbsp;—&nbsp; Infrastructure, DevOps, Docker environments, integrations and long-term maintenance.<br>
**SaaS products** &nbsp;—&nbsp; Multi-tenant products we design, build and operate ourselves.
